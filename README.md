
# Just-Cricket-Portal
A full-stack Progressive Web Application (PWA) developed for Just Cricket Academy to streamline player management, training data collection, and performance analysis across coaching departments.

🌐 Live Application: https://justcricportal.com

🔒 Access restricted to authorized team members only.

---

## 🚀 Project Overview

Just Cricket Portal is a centralized digital platform that enables students, coaches, fitness trainers, and head coaches to efficiently manage training sessions and monitor player progress.

The system replaces manual tracking methods with structured digital workflows, reducing administrative overhead while improving visibility into athlete performance metrics.

The application is accessible on both mobile and desktop devices, and can be installed as a PWA on Android and iOS devices.

🚀 Key Features
🔐 Role-Based Access Control (RBAC)

Separate dashboards for:

Head Coaches

Coaches

Fitness Coaches

Players

Secure role-based data access enforced through Firebase Authentication and Firestore security rules.

📊 Performance Tracking System

Modular performance forms for:

Batting drills

Bowling drills

Fitness sessions

Dynamic player selection with adaptive input fields.

Centralized data visualization through unified dashboards.

🏥 Injury Management Module

Injury logging by fitness coaches and head coaches.

Recovery tracking and return-to-play readiness monitoring.

Structured medical and performance correlation records.

📱 Progressive Web App (PWA)

Installable on Android and iOS.

Offline caching support for quick access during training sessions.

Optimized loading performance and service worker integration.

🔥 Firebase Backend Architecture

Firebase Authentication for secure login.

Cloud Firestore for real-time structured data storage.

Firestore security rules for strict role-based access control.

Firebase Hosting for production deployment.

🎨 Responsive User Interface

Built using Tailwind CSS.

Fully responsive layout for mobile, tablet, and desktop.

Clean dashboard design optimized for quick data entry in training environments.

🛠 Tech Stack

Frontend: Next.js (React Framework)

Backend: Firebase (Authentication + Firestore)

Styling: Tailwind CSS

Hosting: Firebase Hosting

Version Control: GitHub

Architecture: Full-stack PWA with RBAC
